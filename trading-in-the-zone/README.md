# Trading in the Zone

公開交易文章收藏，部署於 GitHub Pages 的 `/trading-in-the-zone/`。

首頁參考知識星球：封面、全文搜尋、文章分類與文章卡片。只收錄文章，不提供手記與靜心工具入口；既有瀏覽器手記資料未清除。

- 亮色沿用淺黃。深色依使用者提供的交易圖：底色 #2b2c32、卡片 #31333b、米白 #e9e7d6、灰藍紫 #c1c2d6，少量綠色 #a6cb8f。
- 原始文章保持七章、七張圖表、三張 SVG 與互動試算，手機表格卡片化、SVG 可橫滑及放大。
- `articles.js` 由文章七章的正文建立全文搜尋資料；每次文章修改應重建。搜尋支援空白分隔關鍵字 AND 比對，顯示命中章節並連至原錨點。
- 封面為生成的山湖暮色與聚焦柔光，位於 `assets/quiet-eye-cover.png`。
- 無建置依賴，直接由既有 main 分支部署。

新增文章時，同步首頁卡片、分類與 `articles.js`。
