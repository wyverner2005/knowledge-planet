# Trading in the Zone

靜下雜念，專注當下。以 Quiet Eye 守住紀律，在每一次等待與執行中，走向理想的生活。

獨立交易記錄網頁，部署於既有 GitHub Pages 的 `/trading-in-the-zone/` 路徑。

- 亮色：柔和淺黃；暗色：炭黑與霧藍。首頁與文章共用偏好。
- 交易手記：新增、編輯、刪除、搜尋、分類、紀律統計、草稿及 JSON 匯出／匯入。
- 手記只儲存於目前瀏覽器的 localStorage，不同步至 GitHub 或 Google Drive。清除瀏覽資料、換瀏覽器或換裝置前請備份。匯入合併不同 ID，同 ID 保留目前版本。
- Quiet Eye：60 秒可暫停的計時與四項進場準備檢核。
- 交易的核心底層邏輯：Drive `trade/01-交易的核心底層邏輯/交易的核心底層邏輯_互動圖文解說.html`，保留七章、七張圖表、三張 SVG、表格篩選、倉位計算及檢核。手機表格轉為卡片，SVG 可橫向滑動與放大。

## 維護

無外部依賴與建置流程。將六個 HTML/CSS/JS 檔與本說明保留於 `trading-in-the-zone/`，由既有 main 分支 GitHub Pages 發布。新增文章時加入同目錄，並更新首頁圖卡與篇數；勿把私人手記 JSON 或個人帳戶資料提交到公開儲存庫。

## 已驗證

桌面與 390px iframe 響應式模擬；亮暗切換與偏好延續；手記儲存、編輯、重新載入、搜尋；行情篩選、圖解放大；倉位 10000 USD × 1% ÷ (100−95) = 20 顆，以及零價差驗證；備份匯出匯入、重複紀錄保留、錯誤日期與錯誤 R 值拒收驗證。手機全頁無水平溢出。以瀏覽器實際操作驗證，未使用手機實機。
