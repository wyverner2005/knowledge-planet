# knowledge-planet
知識星球｜可全文搜尋的圖文醫學筆記

## 新增醫學筆記（/med）

- 在 Notion Medical Wiki 更新原筆記與全庫目錄。原筆記保留 YAML 區塊，並以 Notion 的 `/embed` 區塊直接顯示對應的知識星球 HTML 筆記。文章網址填入嵌入區塊即可，無須另外加入文字超連結或網頁書籤。
- 在 `notes/` 保留同檔名的 `.html` 與 `.yaml`。文章以相對連結提供 YAML 下載，首頁與搜尋索引同步收錄。
- 公開 YAML 使用 `title`、`authors`、`source`、`year`、`volume`、`issue`、`pages`、`type`、`source_type`、`tags` 等適用欄位。只發布公開書目與主題標籤。私人檔案連結、原檔 ID 與整理狀態留在 Notion。
